# Rust AutoWipe

Плагин панели **Catalyst** (catalystctl): расписание вайпов Rust и удаление выбранных
файлов/каталогов через файловый туннель панели.

Это **вкладка сервера**: она появляется в карточке сервера, чей шаблон (яйцо) матчится
`templateFilter: { namePattern: 'rust' }`, и работает только с этим сервером.
Все API-роуты — `/api/plugins/rust-autowipe/servers/:serverId/…`.

## Что умеет

- Расписание: еженедельно, «первый/последний N-й день недели месяца» (вайп Rust),
  день месяца, каждые N дней. Время — в часовом поясе панели.
- Профили этого сервера: расписание + список путей и glob-масок + исключения.
- Сид и размер карты: `WORLD_SEED` (случайный / фиксированный / по списку по очереди)
  и `WORLD_SIZE` (фиксированный / случайный из набора) — значения пишутся в переменные
  шаблона перед запуском.
- Перед удалением останавливает сервер, после — запускает (через REST API панели).
- Файловый пикер: выбор каталогов и файлов прямо в дереве сервера.
- Предпросмотр «что будет удалено» и история прогонов с шагами.
- Dry-run: глобальный в настройках плагина или отдельный у профиля.

## Установка (кратко)

Нужен API-ключ панели с правами `server.start`, `server.stop`
(и `console.write`, если используете команды после запуска).

Скопируйте каталог `rust-autowipe` в `/var/lib/catalyst/plugins/` контейнера
`catalyst-backend` и перезапустите backend **или** установите через маркетплейс:
**Admin → Extensions → Marketplace → Marketplaces → Add**
`https://raw.githubusercontent.com/kafder100/RustWipe/main/index.json`,
затем **Install**. После установки — **Admin → Extensions → Plugins → Enable**.

Настройки плагина: **Admin → Extensions → Plugins → Rust AutoWipe → Settings**.
Обязательные поля: `apiKey`. `panelUrl` можно не заполнять — по умолчанию
используется `http://127.0.0.1:<PORT>` внутри контейнера backend.

Откройте сервер с шаблоном Rust — вкладка **Rust AutoWipe** появится в его карточке.
Владелец сервера видит расписание, а менять профили и запускать вайп могут роли
с `rust-autowipe.manage` / `rust-autowipe.run` (или админ панели).

## Права

Плагин запрашивает:

- `server.read` — читать список серверов и статус;
- `files.read` — просматривать каталоги для пикера;
- `files.write` — удалять выбранные файлы и каталоги.

Для работы сида/размера API-ключу нужно ещё право `server.startup`.

Для пользователей панели плагин объявляет роли: `rust-autowipe.manage` и
`rust-autowipe.run` (Admin → Access Control → Roles). Вкладку видно при встроенном
`server.read` на этом сервере.

## Ограничения

- Плагин работает в процессе панели; ошибки в его коде могут уронить backend.
- Файловый туннель сам не проверяет владельца — плагин на каждом роуте проверяет
  доступ к серверу (владелец, админ или подтверждение панели).
- Удаление необратимо: делайте бэкап сервера перед первым боевым вайпом.
