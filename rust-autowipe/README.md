# Rust AutoWipe

Плагин панели **Catalyst** (catalystctl): расписание вайпов Rust и удаление выбранных
файлов/каталогов через файловый туннель панели.

Это **вкладка сервера**: она появляется в карточке сервера, чей шаблон (яйцо) матчится
`templateFilter: { namePattern: 'rust' }`, и работает только с этим сервером.
Все API-роуты — `/api/plugins/rust-autowipe/servers/:serverId/…`.

## Что умеет

- Расписание: еженедельно, «первый/последний N-й день недели месяца» (вайп Rust),
  день месяца, каждые N дней. Время — в часовом поясе профиля; не выбран — в поясе панели.
- Профили этого сервера: расписание + список путей и glob-масок + исключения.
  Маски: `*`, `?`, `**`; `[*]`, `[?]`, `[[]` — сами символы в имени файла (другие
  квадратные скобки — обычные символы, как раньше).
- Сид и размер карты: `WORLD_SEED` (случайный / фиксированный / по списку по очереди)
  и `WORLD_SIZE` (фиксированный / случайный из набора) — значения пишутся в переменные
  шаблона перед запуском (полным набором переменных, как требует панель). Плагин меняет
  только переменные с `SEED` и `SIZE` в имени.
- Перед удалением останавливает сервер, после — запускает и ждёт статуса `running`
  (через REST API панели). Если сервер остановил плагин, при любой ошибке он поднимает
  его обратно.
- Файловый пикер: выбор каталогов и файлов прямо в дереве сервера.
- Управление списком путей: перетаскивание за `⠿`, кнопки `↑` / `↓`, правка по месту
  (`Enter` — сохранить, `Esc` — отмена), дублирование `⧉`, удаление `×`.
- **Предупреждения в чате сервера** перед плановым вайпом: за `wipeWarningMinutes`
  минут (по умолчанию 5) — по одному сообщению `say …` в минуту. Перед проверкой
  (dry-run) отсчёта нет.
- Предпросмотр «что будет удалено» и история прогонов: каждый шаг раскрывается и
  показывает время, длительность фазы и метрики (пути, удалено, пропущено, ошибки).
- Dry-run («Проверка»): глобальный в настройках плагина или отдельный у профиля. Итог
  проверки хранится отдельно и не затирает итог настоящего вайпа.
- Защита: перед вайпом — окно подтверждения; цель на весь корень сервера запрещена;
  если поиск путей упал или упёрся в предел, вайп не удаляет ничего; если среди
  найденного есть похожее на ссылку (права 777) или странное имя, вайп не начинается.

## Предупреждения в чате

Настройки плагина (**Admin → Extensions → Plugins → Rust AutoWipe → Settings**):

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `wipeWarningEnabled` | `true` | глобальный выключатель |
| `wipeWarningMinutes` | `5` | за сколько минут начинать |
| `wipeWarningText` | `Вайп сервера через {minutes} мин` | текст, `{minutes}` → число минут |

В профиле есть свой переключатель «Предупреждать в чате сервера перед вайпом».
Перед проверкой (dry-run профиля или глобальный `dryRun`) отсчёт не отправляется.
Отметки об отправке хранятся в профиле по времени запуска, поэтому после перезапуска
панели сообщения не дублируются. Требуется право `console.write` у API-ключа.

## Установка (кратко)

Нужен API-ключ панели с правами `server.read`, `server.start`, `server.stop`
(`server.startup` — для сида и размера карты, `console.write` — для команд после
запуска и предупреждений в чат).

Скопируйте каталог `rust-autowipe` в `/var/lib/catalyst/plugins/` контейнера
`catalyst-backend` и перезапустите backend **или** установите через маркетплейс:
**Admin → Extensions → Marketplace → Marketplaces → Add**
`https://raw.githubusercontent.com/kafder100/RustWipe/main/index.json`,
затем **Install**. После установки — **Admin → Extensions → Plugins → Enable**.

Настройки плагина: **Admin → Extensions → Plugins → Rust AutoWipe → Settings**.
Обязательные поля: `apiKey`. Без него нет остановки и запуска, смены карты, чата,
проверки шаблона Rust и входа субпользователей. `panelUrl` можно не заполнять — по
умолчанию используется `http://127.0.0.1:<PORT>` внутри контейнера backend.

Откройте сервер с шаблоном Rust — вкладка **Rust AutoWipe** появится в его карточке.
Админ панели и владелец сервера могут всё без ролей плагина. Субпользователь (есть
в списке доступа сервера с `server.read`) видит вкладку, а менять профили и запускать
вайп может с ролями `rust-autowipe.manage` / `rust-autowipe.run`.

## Права

Плагин запрашивает:

- `server.read` — читать список серверов и статус;
- `files.read` — просматривать каталоги для пикера;
- `files.write` — удалять выбранные файлы и каталоги.

API-ключу панели, которым плагин пользуется для управления сервером, нужны
`server.read`, `server.start`, `server.stop`, `console.write` (команды и предупреждения
в чат) и `server.startup` (запись `WORLD_SEED`/`WORLD_SIZE`). По `server.read` плагин
ещё узнаёт имя шаблона сервера (только Rust) и читает список доступа сервера
(проверка субпользователей). Для чата дополнительно требуется `admin.write`:
консольный роут панели пускает владельца сервера или админа, поэтому не-админский
ключ получает `403` даже с `console.write`. Список доступа чужого сервера панель тоже
отдаёт только админу. Проверить доставку можно кнопкой **«Тест предупреждения»**
в карточке профиля.

Для пользователей панели плагин объявляет роли: `rust-autowipe.manage` (профили и
выбор файлов) и `rust-autowipe.run` (вайп, проверка, тест предупреждения) —
Admin → Access Control → Roles. Вкладку видно при встроенном `server.read` на этом
сервере. Админу и владельцу сервера роли не нужны. Запрос с API-ключом ограничен
правами ключа.

## Ограничения

- Плагин работает в процессе панели; ошибки в его коде могут уронить backend.
- Файловый туннель сам не проверяет владельца — плагин на каждом роуте проверяет
  доступ к серверу (админ, владелец или субпользователь из списка доступа сервера).
- Только серверы Rust: серверу, у которого в имени шаблона нет `rust`, backend отказывает
  (если имя шаблона удалось узнать у панели).
- Ссылку в середине пути и точку монтирования (папку, к которой подключён другой диск)
  плагин не видит: что за ними, удалится как обычные файлы.
- Удаление необратимо: делайте бэкап сервера перед первым боевым вайпом.
